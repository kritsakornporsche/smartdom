# ระบบบริหารจัดการหอพัก (Dormitory Management System)
## สรุปข้อกำหนดข้อมูลสำหรับลงทะเบียน (Data Requirements Specification)

เอกสารนี้สรุปข้อกำหนดข้อมูลที่จำเป็นสำหรับการลงทะเบียนและการออกแบบระบบฐานข้อมูล (Database Schema) ในระบบบริหารจัดการหอพัก โดยแบ่งออกเป็น 2 ส่วนหลัก ได้แก่ **ข้อมูลฝั่งผู้เช่า (Tenant Data)** และ **ข้อมูลฝั่งเจ้าของหอพัก / ผู้ดูแลระบบ (Owner & Admin Data)** พร้อมข้อเสนอแนะด้านกฎหมายคุ้มครองข้อมูลส่วนบุคคล (PDPA)

---

## 1. ข้อมูลฝั่งผู้เช่า (Tenant Data)

ข้อมูลส่วนนี้ใช้สำหรับการระบุตัวตนทางกฎหมาย การทำสัญญาเช่า การจัดส่งใบแจ้งหนี้ ค่าน้ำ-ค่าไฟ การควบคุมความปลอดภัยเข้า-ออกอาคาร และการติดต่อเมื่อเกิดเหตุฉุกเฉิน

| หมวดหมู่ | รายการข้อมูล (Field Name) | ประเภทข้อมูล | ความจำเป็น | วัตถุประสงค์การใช้งาน |
| :--- | :--- | :--- | :--- | :--- |
| **การระบุตัวตน** | ชื่อ - นามสกุล (ไทย/อังกฤษ) | Text | จำเป็น | ใช้ทำสัญญาเช่า และออกใบเสร็จรับเงิน |
| | เลขบัตรประจำตัวประชาชน / พาสปอร์ต | Text | จำเป็น | ยืนยันตัวตนทางกฎหมาย |
| | สำเนาบัตรประชาชน / พาสปอร์ต | File (PDF/Image) | จำเป็น | แนบประกอบสัญญา *(ต้องขีดฆ่าศาสนา/กรุ๊ปเลือด)* |
| | ที่อยู่ตามทะเบียนบ้าน | Text | จำเป็น | ระบุในสัญญาเช่าสำหรับติดต่อตามกฎหมาย |
| **การติดต่อ** | เบอร์โทรศัพท์มือถือหลัก | Text | จำเป็น | ติดต่อประสานงาน และแจ้งเตือนเร่งด่วน |
| | LINE ID / อีเมล | Text | เลือกตอบได้ | ส่งใบแจ้งหนี้ดิจิทัล (E-Invoice) และข่าวสาร |
| | ชื่อ-นามสกุล ผู้ติดต่อฉุกเฉิน | Text | จำเป็น | ติดต่อกรณีเกิดเหตุฉุกเฉินเกี่ยวกับผู้เช่า |
| | ความสัมพันธ์ & เบอร์โทรผู้ติดต่อฉุกเฉิน | Text | จำเป็น | ระบุความสัมพันธ์และช่องทางติดต่อฉุกเฉิน |
| **สัญญา & การเช่า** | เลขที่ห้องพัก / ชั้น / อาคาร | Text | จำเป็น | ระบุตำแหน่งห้องพัก |
| | วันที่เริ่มสัญญา - วันสิ้นสุดสัญญา | Date | จำเป็น | คำนวณระยะเวลาเช่าและแจ้งเตือนต่อสัญญา |
| | จำนวนเงินประกัน / เงินมวดจำ | Decimal | จำเป็น | บันทึกประวัติทางการเงินการเช่า |
| | รายชื่อผู้ร่วมพักอาศัย (Occupants) | Text / List | เลือกตอบได้ | ควบคุมความปลอดภัยและการเข้า-ออกอาคาร |
| **ยานพาหนะ** | ประเภทรถ / ยี่ห้อ / สี | Text | เลือกตอบได้ | จัดสรรพื้นที่จอดรถ |
| | หมายเลขทะเบียนรถ & จังหวัด | Text | เลือกตอบได้ | ออกสติ๊กเกอร์จอดรถ / ตรวจสอบรถเข้า-ออก |
| **การเงิน & เข้าออก** | เลขที่บัญชีธนาคารของผู้เช่า | Text | จำเป็น | โอนเงินประกันคืนเมื่อหมดสัญญา/ย้ายออก |
| | หลักฐานการชำระเงิน (สลิปโอนเงิน) | File (Image) | จำเป็น | ตรวจสอบยอดเงินโอนค่าเช่ารายเดือน |
| | รหัสคีย์การ์ด / ลายนิ้วมือ / สแกนใบหน้า | Encrypted Text | ตามระบบที่ใช้ | Access Control ประตูเข้า-ออกอาคาร |

## 2. ข้อมูลฝั่งเจ้าของหอพัก / ผู้ดูแลระบบ (Owner & Admin Data)

ข้อมูลส่วนนี้ใช้สำหรับการแสดงผลในเอกสารสัญญา หัวใบเสร็จรับเงิน/ใบแจ้งหนี้ การรับชำระเงิน ตลอดจนการกำหนดสิทธิ์ในการเข้าถึงระบบบริหารจัดการ (Backend Control)

| หมวดหมู่ | รายการข้อมูล (Field Name) | ประเภทข้อมูล | ความจำเป็น | วัตถุประสงค์การใช้งาน |
| :--- | :--- | :--- | :--- | :--- |
| **ข้อมูลกิจการ** | ชื่อหอพัก / ชื่อบริษัทประกอบการ | Text | จำเป็น | แสดงบนหัวใบเสร็จ ใบแจ้งหนี้ และสัญญาเช่า |
| | ชื่อ-นามสกุล เจ้าของ / ผู้มีอำนาจลงนาม | Text | จำเป็น | ระบุในฐานะผู้ให้เช่าตามสัญญา |
| | เลขประจำตัวผู้เสียภาษี (Tax ID) | Text | เลือกตอบได้ | ออกใบกำกับภาษี / เอกสารทางบัญชี |
| | ที่อยู่หอพัก / ที่อยู่จดทะเบียน | Text | จำเป็น | ระบุตำแหน่งสถานที่และที่อยู่ในเอกสาร |
| **การรับชำระเงิน** | ชื่อธนาคาร / เลขที่บัญชี | Text | จำเป็น | แจ้งช่องทางการโอนเงินให้ผู้เช่า |
| | ชื่อบัญชีเงินฝาก | Text | จำเป็น | ตรวจสอบความถูกต้องก่อนการโอนเงิน |
| | รูปภาพ PromptPay QR Code | File (Image) | เลือกตอบได้ | แสดงในใบแจ้งหนี้สำหรับให้ผู้เช่าสแกนจ่าย |
| **การติดต่อส่วนกลาง**| เบอร์โทรศัพท์นิติ / แจ้งซ่อม | Text | จำเป็น | ให้ผู้เช่าติดต่อสอบถามหรือแจ้งปัญหา |
| | LINE Official Account / อีเมลส่วนกลาง | Text | เลือกตอบได้ | ช่องทางสื่อสารหลักของหอพัก |
| **บัญชีผู้ใช้งานระบบ**| ชื่อผู้ใช้ (Username) / รหัสผ่าน | Text (Hashed) | จำเป็น | เข้าสู่ระบบบริหารจัดการ (Dashboard) |
| | ระดับสิทธิ์ (Role & Permission) | Enum/Select | จำเป็น | กำหนดสิทธิ์ เช่น Admin, นิติ, แม่บ้าน, ช่างซ่อม |

## 3. ข้อพิจารณาด้านกฎหมายและการรักษาความปลอดภัยข้อมูล (PDPA & Compliance)

ในการพัฒนาระบบและการจัดเก็บข้อมูล ควรคำนึงถึงหลักการสำคัญต่อไปนี้:

1. **หลักการเก็บข้อมูลเท่าที่จำเป็น (Data Minimization):**
   * เก็บเฉพาะข้อมูลที่จำเป็นต่อการทำสัญญาและบริหารหอพักเท่านั้น
   * ไม่ออกแบบฟอร์มบังคับให้กรอกข้อมูลที่ไม่เกี่ยวกับสัญญา เช่น ศาสนา, กรุ๊ปเลือด, หรือรายได้ส่วนบุคคล

2. **การจัดการสำเนาบัตรประชาชน:**
   * ควรมีฟังก์ชันให้ผู้เช่าหรือระบบทำการขีดฆ่า (Mask/Redact) ข้อมูลอ่อนไหว (Sensitive Personal Data) เช่น ศาสนา และ กรุ๊ปเลือด ก่อนทำการบันทึกเข้าฐานข้อมูล

3. **การกำหนดสิทธิ์เข้าถึงข้อมูล (Role-Based Access Control - RBAC):**
   * **Admin / เจ้าของหอ:** เข้าถึงข้อมูลได้ทั้งหมด
   * **พนักงานธุรการ / นิติ:** เข้าถึงข้อมูลผู้เช่า สัญญา และการชำระเงินได้
   * **ช่างซ่อม / แม่บ้าน:** เข้าถึงได้เฉพาะรายการแจ้งซ่อมและหมายเลขห้องพัก *ไม่สามารถดูเอกสารส่วนตัวหรือบัตรประชาชนได้*

4. **ระยะเวลาการจัดเก็บข้อมูล (Data Retention):**
   * ข้อมูลผู้เช่าควรจัดเก็บไว้ตลอดระยะเวลาสัญญา และเก็บต่อเนื่องอีกไม่เกิน 2–10 ปี ตามระยะเวลาอายุความทางกฎหมาย/บัญชี หลังจากนั้นต้องมีระบบ ลบ หรือ ทำให้ออกนาม (Anonymize)
