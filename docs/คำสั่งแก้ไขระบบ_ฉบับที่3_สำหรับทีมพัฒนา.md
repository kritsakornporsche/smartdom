## งานที่ 1: เพิ่มการแจ้งเตือนเจ้าของหอเมื่อผู้เช่าอัปโหลดสลิป

### สภาพปัจจุบัน
ไฟล์ `app/api/tenant/billing/payment/route.ts` เมื่อผู้เช่าอัปโหลดสลิป ระบบทำแค่ `UPDATE bills` เท่านั้น ไม่มีการแจ้งเตือนใด ๆ เจ้าของหอต้องเข้ามาเช็กเอง

### โครงสร้างตาราง notifications (ของจริงในระบบ)
```sql
notifications (
  id          int AUTO_INCREMENT,
  user_id     varchar(100) NOT NULL,
  title       varchar(255) NOT NULL,
  message     text NOT NULL,
  type        varchar(50) DEFAULT 'info',
  is_read     tinyint(1) DEFAULT 0,
  link        varchar(255) DEFAULT NULL,
  created_at  timestamp DEFAULT current_timestamp()
)
```
**หมายเหตุ:** ไม่มีคอลัมน์ `dorm_id` — ต้องหา user_id ของเจ้าของหอจากตาราง `user_dorm_roles` แทน

### โค้ดที่ต้องเพิ่ม

เพิ่มต่อจากบรรทัด `UPDATE bills ...` ในไฟล์ `app/api/tenant/billing/payment/route.ts`

```typescript
// ===== เพิ่มส่วนนี้หลัง UPDATE bills สำเร็จ =====

// 1. หา user_id ของเจ้าของหอและผู้ดูแลของหอพักนี้
const [staff] = await pool.query(
  `SELECT DISTINCT udr.user_id
   FROM user_dorm_roles udr
   WHERE udr.dorm_id = ?
     AND udr.role IN ('owner', 'keeper')`,
  [dormId]
);

// 2. สร้างการแจ้งเตือนให้ทุกคน
for (const person of staff as any[]) {
  await pool.query(
    `INSERT INTO notifications (user_id, title, message, type, is_read, link, created_at)
     VALUES (?, ?, ?, ?, 0, ?, NOW())`,
    [
      person.user_id,
      'มีการแจ้งชำระเงินใหม่',
      `ผู้เช่าห้อง ${roomNumber} แจ้งชำระเงินบิลประจำเดือน ${billMonth} จำนวน ${amount} บาท กรุณาตรวจสอบสลิป`,
      'payment',
      '/owner/billing'
    ]
  );
}
```

**ข้อควรระวัง:**
- ตัวแปร `dormId`, `roomNumber`, `billMonth`, `amount` ต้องดึงมาจาก bill ที่ query ไว้ก่อนหน้า — ถ้ายังไม่มีให้ JOIN ตาราง `bills` กับ `rooms` เพิ่ม
- ตรวจสอบว่าโค้ดเดิมใช้ `pool.query` หรือ library อื่น แล้วปรับให้ตรงกัน

### วิธีทดสอบ
1. ล็อกอินเป็น Tenant → อัปโหลดสลิป
2. ล็อกอินเป็น Owner → ดูว่ามีแจ้งเตือนขึ้นในกระดิ่งหรือไม่
3. เก็บภาพหน้าจอทั้ง 2 ขั้นตอน

## งานที่ 2: ลบระบบสมาชิกและกระเป๋าเงิน (Wallet/Coins/Subscription)

### ข้อมูลสำคัญ
โค้ดส่วนนี้**พังอยู่แล้ว** — `app/api/owner/wallet/route.ts` เรียกตาราง `coin_transactions` ซึ่งไม่มีในฐานข้อมูล ถ้ากดใช้งานจะ error ทันที การลบจึงไม่กระทบผู้ใช้จริง

### 2.1 ลบไฟล์/โฟลเดอร์
```bash
rm -rf app/api/owner/wallet
rm -rf app/api/owner/subscription
rm -rf app/owner/subscription
rm -rf app/api/platform/subscriptions
rm -rf app/platform/subscriptions
rm -rf app/api/platform/packages
```

### 2.2 ลบเมนูออกจาก Sidebar
- `app/owner/components/OwnerSidebar.tsx` → ลบเมนูที่ลิงก์ไป `/owner/subscription`
- `app/platform/components/PlatformSidebar.tsx` → ลบเมนู `/platform/subscriptions` และ `/platform/packages`

### 2.3 แก้ไฟล์ที่อ้างอิงถึง coins/subscription
ตรวจและลบส่วนที่เกี่ยวข้องออกจาก:
- `app/api/owner/onboarding/route.ts`
- `app/api/platform/accounting/route.ts`
- `app/api/platform/dashboard/route.ts`
- `app/api/platform/dormitories/route.ts`
- `app/platform/accounting/page.tsx`
- `app/platform/page.tsx`

### 2.4 ลบในฐานข้อมูล
```sql
-- สำรองก่อนเสมอ
-- mysqldump -u root -p smartdomdb > backup_before_wallet_removal.sql

ALTER TABLE dormitory_registry DROP COLUMN coins;
DROP TABLE IF EXISTS subscriptions;
DROP TABLE IF EXISTS dormitory_packages;
```

**⚠️ อย่าลบ `accounting_transactions`** จนกว่าจะตรวจสอบว่าใช้เก็บรายรับของหอพัก (ต้องเก็บไว้) หรือของแพลตฟอร์ม (ลบได้)

### 2.5 ตรวจว่าไม่มีอะไรพัง
```bash
npm run build
```
ถ้า build ผ่าน แสดงว่าไม่มีไฟล์ไหนอ้างอิงถึงส่วนที่ลบไปแล้ว
