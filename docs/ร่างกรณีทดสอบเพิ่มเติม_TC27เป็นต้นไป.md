# ร่างกรณีทดสอบเชิงฟังก์ชันเพิ่มเติม (TC-27 เป็นต้นไป)

อ้างอิงรูปแบบเดียวกับ TC-01 ถึง TC-26 ที่มีอยู่แล้ว — ทดสอบแบบ Black-Box Testing

**วิธีเก็บข้อมูลแบ่งเป็น 2 แบบตามกลุ่ม** (ดูหมายเหตุท้ายแต่ละหมวด) — ไม่ต้องทำแบบฟอร์ม Google Form หรือเอกสารแยกต่างหาก

---

## หมวดใหม่: การจัดการแพลตฟอร์ม (Admin) — 3 กรณี

| รหัส | กรณีทดสอบ | ผลที่คาดหวัง |
|---|---|---|
| TC-27 | ผู้ดูแลระบบ (Admin) เข้าสู่ระบบและเปิด/ระงับการใช้งานบัญชีหอพัก | สถานะหอพักเปลี่ยนเป็น Active/Suspended ถูกต้อง |
| TC-28 | ผู้ดูแลระบบตรวจสอบรายชื่อผู้เช่าทั้งระบบ | แสดงรายชื่อผู้เช่าครบทุกหอพักที่ลงทะเบียน |
| TC-29 | ผู้ดูแลระบบตรวจสอบสถิติภาพรวมของแพลตฟอร์ม | แสดงจำนวนหอพัก/ผู้เช่า/ห้องพักถูกต้องตรงกับฐานข้อมูล |

**📋 วิธีเก็บข้อมูล (TC-27 ถึง TC-29 เท่านั้น) — แบบละเอียด**

เนื่องจากเป็นบทบาทที่ไม่เคยถูกทดสอบมาก่อนเลย รบกวนเขียนสรุปสั้น ๆ กำกับแต่ละกรณีในไฟล์ Markdown (`docs/TC-27-29-admin-results.md` หรือชื่อใกล้เคียง) ตามรูปแบบนี้:

```
## TC-27: [ชื่อกรณีทดสอบ]
- ขั้นตอนที่ทำ: (อธิบายสั้น ๆ ว่ากดอะไรบ้าง)
- ผลที่ได้จริง: (สิ่งที่เกิดขึ้นจริงบนหน้าจอ)
- ผลการทดสอบ: ผ่าน / ไม่ผ่าน
- ภาพหลักฐาน: [ลิงก์ไฟล์ภาพ]
```

พร้อมภาพหน้าจอประกอบทุกขั้นตอน ตั้งชื่อ `TC-27_step1.png`, `TC-27_step2.png` ตามลำดับ เก็บในโฟลเดอร์ `functional_test_evidence/`

## หมวดใหม่: ฟีเจอร์ที่เพิ่มเข้าขอบเขตภายหลัง — 6 กรณี

| รหัส | กรณีทดสอบ | ผลที่คาดหวัง |
|---|---|---|
| TC-30 | เจ้าของหอพักถ่ายภาพหน้าปัดมิเตอร์ให้ AI อ่านค่าอัตโนมัติ | ระบบอ่านค่าตัวเลขถูกต้องและกรอกให้อัตโนมัติ |
| TC-31 | เจ้าของหอพักและผู้เช่าสนทนากันผ่านระบบแชท | ข้อความถูกส่งและแสดงผลถูกต้องทั้งสองฝั่ง |
| TC-32 | ผู้เช่าส่งคำขอแจ้งย้ายออกพร้อมระบุวันที่และเหตุผล | ระบบบันทึกคำขอสำเร็จ |
| TC-33 | ผู้สนใจติดต่อเจ้าของหอพักและดูตำแหน่งที่ตั้งผ่าน Google Maps | โทร/ส่งข้อความได้ และแผนที่แสดงตำแหน่งถูกต้อง |
| TC-34 | เจ้าของหอพักตรวจสอบรายงานรายรับ-รายจ่ายของหอพัก | แสดงตัวเลขสรุปถูกต้องตรงกับข้อมูลจริง |
| TC-35 | เจ้าของหอพักโพสต์ประกาศข่าวสารใหม่ | ประกาศแสดงผลในบอร์ดข่าวสารของผู้เช่าสำเร็จ |

**📸 วิธีเก็บข้อมูล (TC-30 ถึง TC-35) — แบบภาพหน้าจออย่างเดียว**

เหมือนรอบ TC-19-26 ที่ผ่านมา — ถ่ายภาพหน้าจอแต่ละขั้นตอน ตั้งชื่อ `TC-30_step1.png`, `TC-30_step2.png` ... เก็บในโฟลเดอร์ `functional_test_evidence/` **ไม่ต้องเขียนคำอธิบายกำกับ** ทีมเอกสารจะตีความจากภาพและเขียนผลให้เอง
